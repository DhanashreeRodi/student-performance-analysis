Student Performance Analysis

This project focuses on Python data analysis performed on 100 student records to uncover insights regarding attendance, performance, and student risk factors.

Features
- Data Cleaning: Handling duplicate records and missing information.
- Key Performance Indicators (KPIs): Measuring baseline academic metrics.
- Exploratory Data Analysis (EDA): Breakdown of performance by course, semester, and gender.
- Correlation Tracking:Analyzing how attendance rates impact final performance.
- Risk Classification: Flagging at-risk students using automated Low, Moderate, and High risk profiling.

 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebooks
